# Termux 2.8

A lightweight landing page for the Termux 2.8 project.

## Overview
This project presents the Termux 2.8 experience for Android users, highlighting:
- terminal access
- package management
- developer workflows
- open source usage

## Files

- styles are embedded in the HTML file

## Run locally
